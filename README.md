# farmaka.info

Ελεύθερη, ανοιχτή βάση δεδομένων φαρμάκων για την Ελλάδα. Τιμές, αποζημίωση, επίσημα κείμενα (ΠΧΠ/ΦΟΧ) και κωδικοί, από δημόσιες πηγές, με ιστορικό και πηγή σε κάθε στοιχείο. Δωρεάν για όλους, χωρίς λογαριασμό, χωρίς παρακολούθηση.

> Σε αρχικό στάδιο. Δείτε `docs/ROADMAP.md`.

## Γρήγορη δοκιμή

```bash
python -m pip install -e ".[dev]"
python -m pytest -q
python -m ingest.build --samples
# -> data/current/packages.csv, price_history.csv, packages.json, build_report.json
```

## Πηγές

Υπουργείο Υγείας (δελτία τιμών, κατάλογος αποζημιούμενων), ΕΟΦ (μητρώο, ΠΧΠ/ΦΟΧ), EMA. Λεπτομέρειες στο `docs/DATA_SOURCES.md`.

## Σημαντικό

Η πληροφορία είναι ενημερωτική και δεν υποκαθιστά τη γνώμη γιατρού ή φαρμακοποιού. Η επίσημη πηγή υπερισχύει πάντα.

## Άδειες

Κώδικας και δεδομένα: εκκρεμεί απόφαση (`docs/DECISIONS.md`, Α-1 και Α-2).
