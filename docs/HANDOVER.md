# Handover — farmaka.info

Ημερομηνία: 14/11/2026. Το έγγραφο συνοψίζει όλη τη δουλειά της προετοιμασίας, ώστε να συνεχίσει κάποιος από εδώ χωρίς άλλο context.

## 1. Τι θέλουμε να φτιάξουμε

Μια **ελεύθερη, ανοιχτή και δωρεάν** πηγή πληροφορίας για τα φάρμακα στην Ελλάδα, καλύτερη από τις υπάρχουσες συνδρομητικές. Για φαρμακοποιούς, γιατρούς, νοσηλευτές, φοιτητές, πολίτες, και για όποιον φτιάχνει λογισμικό υγείας.

Η σειρά έχει σημασία: **πρώτα ανοιχτό dataset και API, μετά site.** Αυτό που λείπει σήμερα από την αγορά δεν είναι άλλο ένα UI· είναι μια ανοιχτή, μηχαναγνώσιμη, ενημερωμένη και τεκμηριωμένη βάση που να μπορεί να χρησιμοποιήσει ο καθένας.

## 2. Τοπίο

- **Galinos** (galinos.gr, Ergobyte Πληροφορική Α.Ε., κάτοχος και του σήματος «Galinos»): φάρμακα, ουσίες, ενδείξεις, συσκευασίες, κωδικοποιήσεις (ATC, ICD-10, ICPC-2, πράξεις ΕΟΠΥΥ/ΕΛΟΚΙΠ), εργαλεία συγχορήγησης/αλληλεπιδράσεων, κύηση/γαλουχία, αλλεργίες. Μοντέλο: δωρεάν εγγραφή με πλήρη πρόσβαση για έναν μήνα, μετά συνδρομή. Έχει «Υπηρεσίες δεδομένων», χωρίς δημόσιο API.
- **Mediately** (Σλοβενία, Modra Jagoda d.o.o.): βάση για την Ελλάδα με πηγές ΕΟΦ, EMA, Υπουργείο· δηλώνει >700.000 επαγγελματίες υγείας συνολικά (σε όλες τις χώρες). Δωρεάν βασικό επίπεδο, συνδρομή PRO για αλληλεπιδράσεις κ.λπ.
- **Συμπέρασμα:** το «δωρεάν site» από μόνο του δεν είναι διαφοροποίηση. Η διαφοροποίηση είναι: ανοιχτά δεδομένα + API, ιστορικό τιμών, πηγή σε κάθε στοιχείο, καμία παρακολούθηση, ανοιχτός κώδικας, ελληνική γλώσσα και ελληνικές ιδιαιτερότητες (αποζημίωση, επιβάρυνση ασθενή, εναλλακτικά).

## 3. Τι έχει γίνει

1. **Χαρτογράφηση πηγών** → `docs/DATA_SOURCES.md`.
2. **Ανάλυση πραγματικών αρχείων** του Υπουργείου (πλήρης τιμοκατάλογος 09-2026, δύο δελτία αλλαγών, κατάλογος αποζημίωσης 10-2026). Αποτελέσματα στο `DATA_SOURCES.md`.
3. **Πρωτότυπο ingest** (`ingest/`), δουλεύει:
   - crawler καταλόγου άρθρων με σελιδοποίηση, ταξινόμηση ειδών δελτίου, λήψη συνημμένων, manifest·
   - κανονικοποίηση xlsx με χάρτη επικεφαλίδων (αποτυγχάνει δυνατά σε άγνωστη στήλη)·
   - merge baseline + deltas με ιστορικό τιμών και validation·
   - επαναλήψεις σε timeout και συνέχιση από εκεί που σταμάτησε·
   - ουρά χειροκίνητου ελέγχου για αμφίσημες τιμές (`review_queue` στο `build_report.json`)·
   - 17 tests, offline, πάνω στο `samples/raw/`· CI (GitHub Actions) με ruff + pytest + build.
   - Δοκιμάστηκε σε πραγματικό crawl: λίστα και των 343 άρθρων (2011–2026) και 90 xlsx. Μετά τις διορθώσεις διαβάζονται και τα 90 (62.751 γραμμές)· 2 γραμμές πάνε για έλεγχο.
4. **Σχέδιο μοντέλου δεδομένων** → `docs/SCHEMA.md`.
5. **Αποφάσεις και ανοιχτά** → `docs/DECISIONS.md`.
6. **Roadmap** → `docs/ROADMAP.md`.
7. **Σχέδια αιτημάτων** προς ΕΟΦ, Υπουργείο και ΗΔΥΚΑ → `docs/requests/`.
8. **Όνομα:** farmaka.info (το domain θέλει επιβεβαίωση σε registrar).

## 4. Τα πιο σημαντικά ευρήματα

- Ο **πλήρης τιμοκατάλογος υπάρχει σε xlsx**: το δελτίο «Επικαιροποίηση Δελτίου Τιμών Φαρμάκων με ενσωμάτωση Διοικητικών Μεταβολών». 8.917 συσκευασίες, καθαρά δεδομένα.
- **Κωδικός ΕΟΦ = καθολικό κλειδί.** 9 ψηφία, μοναδικός, μέσα στο barcode (EAN-13, πρόθεμα 280), κοινός σε τιμές και αποζημίωση (join ~99%).
- Τα υπόλοιπα δελτία είναι **αλλαγές**· χρειάζεται merge με σειρά (υλοποιήθηκε). Παράδειγμα: XYDALBA 823,64 € → 547,94 €.
- Υπάρχουν 16 πλήρεις κατάλογοι από το 2020 (άρα ιστορικό και αποσύρσεις ανακατασκευάζονται) και 7 ετήσιες «αναθεωρήσεις» κάθε Δεκέμβρη, που μένει να ελεγχθούν.
- Τα αρχεία έχουν **πραγματικές βρωμιές**: τιμές ως κείμενο με υποδιαστολή, δύο τιμές στο ίδιο κελί, ΦΠΑ ως `"6%"`, νέες παραλλαγές επικεφαλίδων. Ο κώδικας αποτυγχάνει δυνατά ή στέλνει σε έλεγχο· δεν μαντεύει.
- Ο **κατάλογος αποζημίωσης είναι μόνο pdf**, αλλά με σταθερή στοίχιση (JasperReports) → parsing εφικτό. Έχει πλούσια πεδία (DDD, ΑΗΔ, ΚΗΘ, τιμή αποζημίωσης, περιορισμούς). Τα κείμενα κόβονται· πλήρη ονόματα από τον τιμοκατάλογο μέσω κωδικού. Μορφή αριθμών διαφέρει ανά αρχείο.
- Το **moh.gov.gr θέλει browser User-Agent**· χωρίς αυτό κόβει τη σύνδεση. Κόβει συνδέσεις και όταν το πιέζεις (~400 αιτήματα): crawl με παύση 3 s και σε δόσεις.
- Ο **ΕΟΦ (ΠΧΠ/ΦΟΧ) είναι το μπλοκάρισμα**: το robots.txt απαγορεύει crawling της αναζήτησης. Πάμε με επίσημο αίτημα (ν. 4727/2020). Ο ΕΟΦ τρέχει πιλοτικό e-PIL από 06/2026 — αφορμή συνεργασίας.
- **Αλληλεπιδράσεις:** η μόνη έτοιμη ανοιχτή πηγή (DDInter 2.0) έχει μη εμπορική share-alike άδεια → χωριστό επίπεδο. Κανονιστικό ρίσκο MDR για εξατομικευμένο έλεγχο → ρητά εκτός μέχρι νομικό έλεγχο.

## 5. Περιορισμοί που δεν συζητιούνται

- Μόνο δημόσιες πηγές ή πηγές με άδεια. **Τίποτα από Galinos/Mediately** (δικαίωμα κατασκευαστή βάσης, Οδηγία 96/9/ΕΚ).
- Όχι scraping όπου το robots.txt το απαγορεύει.
- Πηγή και ημερομηνία σε κάθε στοιχείο, στα δεδομένα και στο UI.
- Χωρίς tracking, cookies, τρίτα scripts, λογαριασμούς (MVP).
- Ενημερωτικός χαρακτήρας, όχι κλινική απόφαση· disclaimer.
- Ανοιχτός κώδικας και δεδομένα.

## 6. Πώς ξεκινάς

```bash
python -m pip install -e ".[dev]"
python -m pytest -q
python -m ingest.build --samples
python -m ingest.fetch --section prices --out data --max-pages 2   # πρόσφατα μόνο· το πλήρες ιστορικό σε δόσεις, βλ. DATA_SOURCES
python -m ingest.build --manifest data/manifest_prices.json --raw data/raw --out data/current
```

Το `data/` δεν μπαίνει στο git.

## 7. Προτεινόμενη πρώτη συνεδρία εργασίας

Με σειρά, το καθένα με test:

1. Στήσε `.gitignore` (`data/`, `__pycache__`, `.venv`), CI (pytest + ruff).
2. Ολοκλήρωσε το crawl των δελτίων τιμών (το πρώτο σταμάτησε στα 90 xlsx από timeout· ο crawler πλέον συνεχίζει). Για **κάθε** xlsx: `read_bulletin`. Μάζεψε τις `UnknownHeader`· πρόσθεσε τις παραλλαγές στο `_VARIANTS` με test.
3. Λύσε τις 2 γραμμές του `review_queue` διαβάζοντας τα pdf των αντίστοιχων Υ.Α. (άρθρα 14110, 12962) και γράψε κανόνα.
4. Κατέβασε ένα `revision` (π.χ. άρθρο 13924, Δεκέμβριος 2025) και αποφάσισε αν είναι πλήρης κατάλογος και άρα baseline.
5. Χειρισμός `amendment`: δες 3–4 παραδείγματα, σχεδίασε πώς αλλάζουν ήδη εφαρμοσμένα delta.
6. Κάνε κάθε παλαιότερο `full` snapshot· παρήγαγε αποσύρσεις (Α-4) και πλήρες ιστορικό.
7. Μετέφερε το build σε SQLite σύμφωνα με το `docs/SCHEMA.md` (Package, PriceEvent, Source πρώτα).
8. Ξεκίνα τον parser αποζημίωσης (`ingest/reimbursement.py`) πάνω στα δύο pdf του `samples/raw/`: γραμμές συσκευασίας, ιεραρχία ATC, οδός, περιορισμοί· test ότι βγαίνουν 5.678 και 1.588 κωδικοί αντίστοιχα.
9. Ενημέρωσε `DATA_SOURCES.md` και `DECISIONS.md` με ό,τι μάθεις.
