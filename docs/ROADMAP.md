# Roadmap

Χρονισμοί σε εβδομάδες από την έναρξη, για μία-δύο ώρες δουλειάς την ημέρα. Οι φάσεις 2–3 εξαρτώνται από απαντήσεις φορέων, άρα τρέχουν παράλληλα με ό,τι δεν μπλοκάρεται.

## Φάση 0 — Θεμέλια (εβδ. 1)

- [ ] Repo (δημόσιο), CI με pytest + ruff, άδειες (Α-1, Α-2).
- [ ] Κατοχύρωση `farmaka.info` (Δ-1) και απόφαση για `farmaka.gr`.
- [ ] Αποστολή αιτημάτων: ΕΟΦ (`docs/requests/eof-aitima-dedomenon.md`), Υπουργείο για μηχαναγνώσιμο κατάλογο αποζημίωσης (`docs/requests/moh-aitima-katalogou.md`).
- [ ] Απόφαση φορέα (Α-3).

**Τέλος φάσης:** ο κώδικας είναι δημόσιος, τα αιτήματα έχουν φύγει με αριθμό πρωτοκόλλου.

## Φάση 1 — Τιμές: πλήρες και αξιόπιστο (εβδ. 1–3)

- [x] Πρωτότυπο: crawl, κανονικοποίηση xlsx, baseline + deltas, ιστορικό, validation, ουρά ελέγχου.
- [x] Λίστα όλων των 343 άρθρων και ταξινόμηση τίτλων (μένουν 16 προ του 2020).
- [ ] Ολοκλήρωση λήψης όλων των xlsx (έγιναν 90)· έλεγχος όλων των παραλλαγών επικεφαλίδων· tests για κάθε νέα.
- [ ] Απόφαση για τα `revision` (Δεκεμβριανές αναθεωρήσεις) ως baseline.
- [ ] Ανακατασκευή ιστορικού από όλα τα παλαιότερα `full` (κάθε `full` γίνεται snapshot → αποσύρσεις, Α-4).
- [ ] Χειρισμός `amendment` (χειροκίνητη ουρά ελέγχου + κανόνες).
- [ ] Εξαγωγή ημερομηνίας ισχύος από τα pdf των Υ.Α. (Α-5).
- [ ] Ανάλυση ονομασίας: μορφή (λεξικό συντομογραφιών), περιεκτικότητα, μέγεθος συσκευασίας.
- [ ] Αποδιπλοποίηση ΚΑΚ (πίνακας alias).
- [ ] Καθημερινό job: crawl → build → αν άλλαξε κάτι, νέο release με changelog.
- [ ] Πρώτο δημόσιο release: `packages.csv/json`, `price_history.csv`, `farmaka.sqlite`, checksums.

**Τέλος φάσης:** κάθε μέρα υπάρχει ενημερωμένος, ελεγμένος, ανοιχτός τιμοκατάλογος με ιστορικό. Μηδέν σφάλματα σε EAN/κωδικό/σειρά τιμών· κάθε γνωστό κενό τεκμηριωμένο.

## Φάση 2 — Αποζημίωση (εβδ. 2–5)

- [ ] Parser για τα pdf του καταλόγου (κύριος + Ν3816) με θέσεις στηλών, ιεραρχία ATC, οδό χορήγησης, περιορισμούς.
- [ ] Χειρισμός διαφορετικής μορφής αριθμών ανά αρχείο.
- [ ] Join με τιμές μέσω κωδικού· αναφορά για ό,τι δεν ταιριάζει.
- [ ] Ενδιάμεσες εντάξεις/απεντάξεις ως γεγονότα.
- [ ] Αποκωδικοποίηση σημαιών `Σ`, `Τ` (Α-11).
- [ ] Υπολογισμός «επιπλέον επιβάρυνσης ασθενή» (λιανική − αποζημίωση) και φθηνότερων εναλλακτικών ίδιας ουσίας/μορφής/περιεκτικότητας.

**Τέλος φάσης:** για κάθε συσκευασία ξέρουμε αν αποζημιώνεται, με ποια τιμή, με ποιους περιορισμούς, και ποια είναι τα φθηνότερα ισοδύναμα.

## Φάση 3 — Μητρώο και επίσημα κείμενα (εβδ. 4–10, εξαρτάται από ΕΟΦ)

- [ ] Ενσωμάτωση dump/API ΕΟΦ (όταν έρθει): άδειες, κατάσταση, τρόπος διάθεσης, ΠΧΠ/ΦΟΧ με εκδόσεις.
- [ ] EMA: κεντρικά εγκεκριμένα, ελληνικές ΠΧΠ/ΦΟΧ, έλεγχος ePI API.
- [ ] Αποθήκευση εγγράφων με hash και ειδοποίηση όταν αλλάζει ΠΧΠ (χρήσιμο μόνο του για επαγγελματίες).
- [ ] Εξαγωγή ενοτήτων ΠΧΠ (4.1 ενδείξεις, 4.3 αντενδείξεις, 4.5 αλληλεπιδράσεις, 4.6 κύηση/γαλουχία) σε δομημένη μορφή, συμβατή με ePI.

**Plan B αν ο ΕΟΦ δεν απαντήσει σε ~6 εβδομάδες:** υπενθύμιση/αίτημα πρόσβασης, επικοινωνία μέσω επαγγελματικών συλλόγων, και στο μεταξύ μόνο EMA.

## Φάση 4 — Δημόσιο site MVP (εβδ. 6–10)

- [ ] Αναζήτηση (εμπορικό όνομα, ουσία, κωδικός, barcode), ανοχή σε τόνους και greeklish.
- [ ] Σελίδα συσκευασίας: τιμές + ιστορικό (γράφημα), αποζημίωση, εναλλακτικά, ΠΧΠ/ΦΟΧ, πηγή και ημερομηνία παντού.
- [ ] Σελίδες ουσίας και ATC.
- [ ] PWA/offline, σάρωση barcode από κινητό.
- [ ] Προσβασιμότητα WCAG 2.1 AA, χωρίς τρίτα scripts, χωρίς cookies.
- [ ] Σαφές disclaimer και σελίδα «Από πού έρχονται τα δεδομένα».

**Τέλος φάσης:** ένας φαρμακοποιός βρίσκει τιμή, αποζημίωση και ΠΧΠ για οποιοδήποτε σκεύασμα σε <5 s από κινητό.

## Φάση 5 — API και ενσωματώσεις (εβδ. 8–12)

- [ ] Read-only REST API (ίδια πεδία με τα dumps), τεκμηρίωση OpenAPI, χωρίς κλειδί για λογική χρήση.
- [ ] Webhooks/feeds αλλαγών (RSS/Atom ανά ουσία ή ΚΑΚ).
- [ ] Παραδείγματα ενσωμάτωσης για λογισμικό φαρμακείων/ιατρείων.

## Φάση 6 — Κλινικό επίπεδο (μετά από νομικό έλεγχο, Α-6)

- [ ] Νομική γνωμάτευση για MDR.
- [ ] Αλληλεπιδράσεις: προβολή ανά ουσία (όχι ανά ασθενή) από ΠΧΠ 4.5 και/ή DDInter με σαφή σήμανση πηγής και άδειας (Α-10).
- [ ] Κύηση/γαλουχία, αντενδείξεις από τις αντίστοιχες ενότητες ΠΧΠ.
- [ ] Μόνο αν η γνωμάτευση το επιτρέπει: έλεγχος πολλών φαρμάκων μαζί.

## Φάση 7 — Κοινότητα και βιωσιμότητα (συνεχές)

- [ ] Οδηγός συνεισφοράς, αναφορά λαθών δεδομένων από χρήστες (με επαλήθευση από πηγή).
- [ ] Αίτηση χρηματοδότησης (Α-8).
- [ ] Επαφή με ΠΦΣ, ιατρικούς συλλόγους, πανεπιστημιακά τμήματα φαρμακευτικής για επιστημονική επιμέλεια.
- [ ] Δημόσια σελίδα κατάστασης: πότε ενημερώθηκε κάθε πηγή.

## Μετρικές επιτυχίας (χωρίς tracking χρηστών)

- Καθυστέρηση ενημέρωσης: δημοσίευση δελτίου → δικό μας release < 24 ώρες.
- Κάλυψη: % συσκευασιών με τιμή, αποζημίωση, ΠΧΠ.
- Ακρίβεια: 0 γνωστά λάθη τιμών ανοιχτά > 48 ώρες.
- Υιοθέτηση: αριθμός λήψεων dumps (από server logs, χωρίς προσωπικά δεδομένα), αριθμός γνωστών ενσωματώσεων.
