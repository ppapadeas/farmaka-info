# Roadmap

Κατάσταση στις 15/11/2026. Το site είναι δημόσιο στο https://farmaka.info και ενημερώνεται αυτόματα κάθε μέρα.
Οι φάσεις 2–3 εξαρτώνται εν μέρει από απαντήσεις φορέων, άρα τρέχουν παράλληλα με ό,τι δεν μπλοκάρεται.

## Φάση 0 — Θεμέλια

- [x] Δημόσιο repo στο GitHub, CI με pytest, ruff και tests JS.
- [x] Άδειες: κώδικας AGPL-3.0, δεδομένα CC0 (Δ-9).
- [x] Κατοχύρωση `farmaka.info` στο Cloudflare (Δ-1). Το `farmaka.gr` παραμένει ανοιχτό θέμα.
- [x] Αποστολή αιτημάτων με email στις 21/11/2026: ΕΟΦ (`docs/requests/eof-aitima-dedomenon.md`), Υπουργείο για
  μηχαναγνώσιμο κατάλογο αποζημίωσης (`docs/requests/moh-aitima-katalogou.md`) και ΗΔΥΚΑ για τους κωδικούς
  ICD-10 που δέχεται η συνταγογράφηση ανά δραστική ουσία (`docs/requests/hdyka-aitima-icd10.md`).
- [ ] Απαντήσεις στα αιτήματα. Η Οδηγία (ΕΕ) 2019/1024 (άρθρο 4) δίνει 20 εργάσιμες, με δυνατότητα παράτασης
  άλλες 20: απάντηση έως 18/12/2026 ή, με παράταση, μέσα Ιανουαρίου 2027. Χωρίς τον πίνακα της ΗΔΥΚΑ δεν
  δείχνονται κωδικοί ICD-10 ανά φάρμακο.
- [ ] Απόφαση φορέα (Α-3). Προσωρινά ατομικό project (Δ-13).

- [x] Λήψη και των 16 πλήρων καταλόγων (2020–2026) και όλων των νεότερων δελτίων· νέες παραλλαγές επικεφαλίδων με
  tests.
- [x] Ιστορικό από όλους τους πλήρεις καταλόγους: `first_seen`, `update`, `withdrawn`, `reappeared` (Α-4).
- [x] Προέλευση σε κάθε τιμή (δελτίο, ημερομηνία, άρθρο) και δημόσια λίστα δελτίων σε αναμονή (Δ-12).

- [ ] Αποδιπλοποίηση ΚΑΚ (πίνακας alias) και ενοποίηση παραλλαγών ουσίας (π.χ. ATORVASTATIN / … CALCIUM TRIHYDRATE).

## Φάση 2 — Αποζημίωση

  περιορισμοί, αριθμοί ανά αρχείο.
- [x] Join με τις τιμές μέσω κωδικού ΕΟΦ.
- [x] Επιπλέον επιβάρυνση ασθενή (λιανική − τιμή αποζημίωσης, με την τρέχουσα λιανική).
- [x] Φθηνότερα ισοδύναμα: ίδια ουσία, περιεκτικότητα και μορφή, ανά τεμάχιο (Δ-16, Οδηγία 2001/83 άρθρο 10).
- [x] «Πόσο θα πληρώσω;»: ενδεικτικό ποσό για συμμετοχή 0, 10 και 25%, και για το φθηνότερο ισοδύναμο (Δ-22).

- [ ] Ενδιάμεσες εντάξεις/απεντάξεις ως γεγονότα (σήμερα μόνο ο κατάλογος 10/2026, από τα samples).
- [ ] Αυτόματη λήψη του εκάστοτε νέου καταλόγου από το moh.gov.gr.
- [ ] Αποκωδικοποίηση σημαιών `Σ`, `Τ` (Α-11).

## Φάση 3 — Μητρώο και επίσημα κείμενα

- [x] EMA: σύνδεσμοι στα ελληνικά ΠΧΠ/ΦΟΧ για 1.896 συσκευασίες κεντρικά εγκεκριμένων φαρμάκων (Δ-17).
- [x] ΕΟΦ: πολύ αργός νυχτερινός crawler (Δ-18), σύνδεσμοι σε ΠΧΠ/ΦΟΧ στις σελίδες. Το πλήρες crawl θέλει ~11 νύχτες.
- [x] Δομημένα ΠΧΠ/ΦΟΧ της EMA σε ενότητες και σελίδες ανάγνωσης (`/fylla/`): 840 προϊόντα (Δ-20). Μένουν 5 pdf
  με γραμματοσειρές που δεν διαβάζονται (θέλουν pdfium) και 2 με λάθος γλώσσα στην EMA.
- [x] Ελλείψεις: λίστες επάρκειας και διακοπών του ΕΟΦ, κατάλογος ελλείψεων της EMA· ένδειξη σε κάθε σελίδα και
  `/elleipseis/`, με τα ισοδύναμα που δεν είναι σε έλλειψη. Η απαγόρευση παράλληλων εξαγωγών δημοσιεύεται μόνο
  σκαναρισμένη: εκκρεμεί (αίτημα ή OCR).
- [x] Το φύλλο οδηγιών μέσα στη σελίδα της συσκευασίας: «Με μια ματιά» (αυτούσια αποσπάσματα με σταθερούς
  κανόνες) και όλο το κείμενο σε ενότητες, με πίνακα περιεχομένων· το σωστό φύλλο ανά περιεκτικότητα/μορφή (Δ-23).
- [~] Το ίδιο για τα έγγραφα του ΕΟΦ (Δ-24): pdf, doc, docx, rtf με τον ίδιο parser, στη σελίδα της συσκευασίας
  (φύλλο οδηγιών και ΠΧΠ). Η πλήρης λήψη (6.595 προϊόντα μαζί με τα ΜΗΣΥΦΑ, ~90 ώρες αιτημάτων) τρέχει με διαδοχικές εκτελέσεις.
- [ ] Επανέλεγχος για νέες εκδόσεις εγγράφων και ειδοποίηση όταν αλλάζει ΠΧΠ.
- [~] Ελληνικά ονόματα ουσιών: 673, από Wikidata και από τα ελληνικά ΦΟΧ της EMA (69% των συσκευασιών)· τα
  υπόλοιπα όταν αναλυθούν τα έγγραφα του ΕΟΦ.

**Plan B αν ο ΕΟΦ ζητήσει διακοπή:** αρχείο `data/eof/STOP`, μόνο EMA, και επίσημο αίτημα.

## Μετρικές επιτυχίας (χωρίς tracking χρηστών)

- Καθυστέρηση ενημέρωσης: δημοσίευση δελτίου → δικό μας deploy < 24 ώρες (σήμερα: το πρωινό job).
- Κάλυψη: % συσκευασιών με τιμή, αποζημίωση, ΠΧΠ/ΦΟΧ (σήμερα ΠΧΠ/ΦΟΧ: EMA 1.896 + ΕΟΦ σε εξέλιξη).
- Ακρίβεια: 0 γνωστά λάθη τιμών ανοιχτά > 48 ώρες.
- Υιοθέτηση: λήψεις dumps (από logs χωρίς προσωπικά δεδομένα), γνωστές ενσωματώσεις.
